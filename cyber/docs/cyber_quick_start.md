# Apollo Cyber RT Quick Start

## How to create a new component with Cyber RT

The Apollo Cyber RT framework is built on the concept of components. Each component is a specific algorithm module of the Cyber RT framework, which processes a set of inputs and produces its output
data.

To create and launch an algorithm component, you need to go through the following 4 steps:

- Initialize the component's directory structure
- Implement the component class
- Set up the configuration files
- Launch the component

The example below shows how to create, build and run a component. To explore the Cyber RT framework in more depth and learn about its various features, see the additional examples in the `cyber/examples/` directory.

_Note: These examples must be run inside the Apollo Docker environment and must be built with Bazel._

### Initialize the component's directory structure

Take the sample program in the `cyber/examples/common_component_example/` directory as an example:

- C++ header file: common_component_example.h
- C++ source file: common_component_example.cc
- Bazel build file: BUILD
- DAG file: common.dag
- Launch file: common.launch

### Implement the component class

#### Header file

How to implement `common_component_example.h`:

- Inherit from the Component class
- Define your own `Init` and `Proc` functions. Proc needs to specify the input data types.
- Use the `CYBER_REGISTER_COMPONENT` macro to register the component class so that it is globally available.

```cpp
#include <memory>

#include "cyber/component/component.h"
#include "cyber/examples/proto/examples.pb.h"

using apollo::cyber::Component;
using apollo::cyber::ComponentBase;
using apollo::cyber::examples::proto::Driver;

class CommonComponentSample : public Component<Driver, Driver> {
 public:
  bool Init() override;
  bool Proc(const std::shared_ptr<Driver>& msg0,
            const std::shared_ptr<Driver>& msg1) override;
};
CYBER_REGISTER_COMPONENT(CommonComponentSample)
```

#### Source file

For the source file `common_component_example.cc`, the `Init` and `Proc` functions need to be implemented.

```cpp
#include "cyber/examples/common_component_example/common_component_example.h"

bool CommonComponentSample::Init() {
  AINFO << "Commontest component init";
  return true;
}

bool CommonComponentSample::Proc(const std::shared_ptr<Driver>& msg0,
                                 const std::shared_ptr<Driver>& msg1) {
  AINFO << "Start common component Proc [" << msg0->msg_id() << "] ["
        << msg1->msg_id() << "]";
  return true;
}
```

#### Create the BUILD file

```python
load("@rules_cc//cc:defs.bzl", "cc_binary", "cc_library")
load("//tools:cpplint.bzl", "cpplint")

package(default_visibility = ["//visibility:public"])

cc_binary(
    name = "libcommon_component_example.so",
    linkshared = True,
    linkstatic = False,
    deps = [":common_component_example_lib"],
)

cc_library(
    name = "common_component_example_lib",
    srcs = ["common_component_example.cc"],
    hdrs = ["common_component_example.h"],
    visibility = ["//visibility:private"],
    deps = [
        "//cyber",
        "//cyber/examples/proto:examples_cc_proto",
    ],
)
cpplint()
```

### Set up the configuration files

#### Configure the DAG file

In the DAG dependency configuration file (for example common.dag), configure the following items:

- Channel names: the names of the input channels
- Library path: the path of the shared library generated by this component
- Class name: the name of this component class

```bash
# Define all components in DAG streaming.
module_config {
module_library : "/apollo/bazel-bin/cyber/examples/common_component_example/libcommon_component_example.so"
components {
    class_name : "CommonComponentSample"
    config {
        name : "common"
        readers {
            channel: "/apollo/prediction"
        }
        readers {
            channel: "/apollo/test"
        }
    }
  }
}
```

#### Configure the Launch file

In the launch file (`common.launch`), configure the following items:

- The name of the component
- The path of the DAG file configured in the previous step
- The process name used when running the component

```xml
<cyber>
    <component>
        <name>common</name>
        <dag_conf>/apollo/cyber/examples/common_component_example/common.dag</dag_conf>
        <process_name>common</process_name>
    </component>
</cyber>
```

### Launch the component

Build the component with the following command:

```bash
cd /apollo
bash apollo.sh build
```

Then set up the environment:

```bash
source cyber/setup.bash
# Observe the output from the terminal
export GLOG_alsologtostderr=1
```

There are two ways to launch the component:

- Launch using the Launch file (recommended)

```bash
cyber_launch start cyber/examples/common_component_example/common.launch
```

- Launch using the DAG file

```bash
mainboard -d cyber/examples/common_component_example/common.dag
```

#### Provide channel data for the component to process

Open another terminal and run:

```bash
source cyber/setup.bash
export GLOG_alsologtostderr=1
/apollo/bazel-bin/cyber/examples/common_component_example/channel_test_writer
```

Open yet another terminal and run:

```bash
source cyber/setup.bash
export GLOG_alsologtostderr=1
/apollo/bazel-bin/cyber/examples/common_component_example/channel_prediction_writer
```
