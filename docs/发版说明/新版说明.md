## Major Updates

Apollo 8.0 introduced the concept of package management for learning scenarios, making it easier and faster for users to deploy and use Apollo. In Apollo 9.0, Package Management 2.0 makes it easier for users to build on top of Apollo for secondary development and to create their own autonomous driving applications. Apollo 10.0 is a comprehensive upgrade aimed at large-scale deployment in scenario-based applications. In terms of performance, it optimizes the performance and stability of every layer and module, and provides rich tools to improve optimization efficiency. Apollo 11.0 focuses on the large-scale deployment of **functional unmanned vehicles** in high-value scenarios, with a comprehensive upgrade of perception, localization, planning and the development toolchain, significantly lowering the barrier to hardware and software development and helping developers efficiently build end-to-end autonomous operation systems.

The main new features of Apollo open-source platform 11.0 are as follows:

## 1. Expanded Application Scenarios for Functional Unmanned Vehicles, Achieving an End-to-End Operation Loop

Apollo 11.0 targets typical scenarios such as **express delivery, sanitation and street cleaning, security patrol, and campus shuttles**, and opens up a number of key capabilities:

-  **Slope start and stop**: adapts to start/stop needs on complex terrain  
-  **Automatic escape**: improves autonomous recovery under abnormal road conditions  
-  **Curb-hugging driving**: runs precisely along curbs or boundaries  

It fully supports end-to-end automation of the complete workflow: **departure preparation → route setting → autonomous driving → task execution (such as cleaning, retail, passenger transport) → exception takeover → return to depot and parking**.

## 2. Multi-Source Fusion Localization + Scenario Perception Upgrades, Strengthening All-Domain Operation

-  **Industrial-grade high-precision localization solution**: fuses RTK / SLAM / vision / wheel speed to achieve **centimeter-level localization** in weak-signal environments such as **dense buildings, underground garages, and fully indoor spaces**.
-  **New barrier gate recognition**: closes the autonomous driving loop between **open roads and enclosed campuses**.
-  **Perception upgrade**: significantly improves the recognition accuracy of static obstacles such as **curbs, retaining walls, and road potholes**.
-  **Upgraded BEV + OCC perception architecture**: deeply integrated with the **Baidu Baige AI computing platform**, providing a one-stop workflow of **model development → training → conversion → export**.
-  **Incremental training support**: developers can quickly fine-tune pretrained models with their own data, accelerating model iteration.

With the support of hardware-software co-design and ecosystem tools, Apollo 11.0 significantly lowers the development barrier and deployment cost of functional unmanned vehicles and accelerates commercialization.
