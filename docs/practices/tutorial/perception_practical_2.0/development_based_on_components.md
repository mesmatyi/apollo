# Development Based on Components

The goal of this practice session is to develop a component and illustrate the process of developing a perception component. The development goal is to build a complete component framework and implement an example function: identifying objects through clustering. This component is used to replace the lidar_detection component and can perform CPU-based LiDAR perception.

## Preparation

- [Environment configuration](https://apollo.baidu.com/community/article/1133).
- [Perception function debugging and parameter tuning](https://apollo.baidu.com/community/article/1134).

Enter the container:

```bash
# Enter the application-perception code repository
cd application-perception

# Pull and start the docker container; this command is not needed if it has already been pulled
aem start_gpu
# Enter the container
aem enter
# Download and install dependency packages: this installs all the dependency packages in cyberfile.xml under the core directory
buildtool build --gpu
```

Components are created through a command; after the command is executed, the code framework is created automatically.

## Create a component

After entering the container, run the command to create the component.

```bash
#Create the component; --namespace specifies the namespace, --template specifies that a component is being created, and the last argument is the component path
buildtool create --namespace perception --template component modules/perception/lidar_cluster_component
```

## Component development

This component is applied to LiDAR perception. The component generated by the command has some default configuration that needs to be modified and developed. Rename the lidar_cluster_component folder to lidar_cluster to keep the lidar component names consistent.

### Function development

Define the interface of the cluster method. Create a new lidar_cluster/interface folder, in which the interface class is defined.

```bash

#include "cyber/common/macros.h"
```

Implement the clustering function code. Create a new lidar_cluster/cluster folder, which holds all the clustering methods. This component uses Euclidean clustering as an example; create the folder euclidean_cluster in cluster.

Define euclidean_cluster.h and euclidean_cluster.cc in euclidean_cluster.

```bash
#pragma once

#include <string>
#include <vector>
#include <map>

#include <pcl/point_types.h>
#include <pcl/io/pcd_io.h>
```

The clustering source code is as follows:

```bash
#include "modules/perception/lidar_cluster/cluster/euclidean_cluster/euclidean_cluster.h"

namespace apollo {
namespace perception {
namespace lidar {

using apollo::cyber::common::GetProtoFromFile;

bool EuclideanCluster::Init(const ObjectClusterInitOptions& options) {
    std::string config_file = GetConfigFile(options.config_path, options.config_file);
    // get euclidean cluster params
    euclidean_cluster_param_.Clear();
    ACHECK(GetProtoFromFile(config_file, &euclidean_cluster_param_))  // 1. Load the algorithm parameters
            << "Failed to parse EuclideanClusterConfig config file.";

    return true;
}

bool EuclideanCluster::Cluster(const ObjectClusterOptions& options, LidarFrame* frame) {
    // check input
    if (frame == nullptr) {
        AERROR << "Input null frame ptr.";
        return false;
    }
    if (frame->cloud == nullptr) {
        AERROR << "Input null frame cloud.";
        return false;
    }
    if (frame->cloud->size() == 0) {
        AERROR << "Input none points.";
        return false;
    }
    // obtain intersection of roi and non-ground indices
    CloudMask mask;
    mask.Set(frame->cloud->size(), 0);
    mask.AddIndicesOfIndices(frame->roi_indices, frame->non_ground_indices, 1);
    base::PointIndices indices;
    mask.GetValidIndices(&indices);  // 2. Get the intersection of the roi and non-ground points. (When the ego vehicle is on the map, the points within the map are roi points; when the ego vehicle is not on the map, all points are roi points)
    // get pointcloud of indices
    std::map<int, int> index_mapper_;  // key: index-in-pcl_cloud, value: index-in-cloud
    pcl::PointCloud<pcl::PointXYZ>::Ptr pcl_cloud(new pcl::PointCloud<pcl::PointXYZ>);
    pcl_cloud->reserve(indices.indices.size());
    for (size_t i = 0; i < indices.indices.size(); ++i) {
        int idx = indices.indices.at(i);
        index_mapper_[i] = idx;
        // get point
        auto pt = frame->cloud->at(idx);
        pcl::PointXYZ pcl_pt;
        pcl_pt.x = pt.x;
        pcl_pt.y = pt.y;
        pcl_pt.z = pt.z;
        pcl_cloud->push_back(pcl_pt);
    }
    // 3. Main flow of the Euclidean clustering algorithm
    // kd tree
    pcl::search::KdTree<pcl::PointXYZ>::Ptr tree(new pcl::search::KdTree<pcl::PointXYZ>);
    tree->setInputCloud(pcl_cloud);
    // do euclidean cluster
    std::vector<pcl::PointIndices> cluster_indices;
    pcl::EuclideanClusterExtraction<pcl::PointXYZ> ec;
    ec.setClusterTolerance(euclidean_cluster_param_.cluster_distance());
    ec.setMinClusterSize(euclidean_cluster_param_.min_cluster_size());
    ec.setMaxClusterSize(euclidean_cluster_param_.max_cluster_size());
    ec.setSearchMethod(tree);
    ec.setInputCloud(pcl_cloud);
    ec.extract(cluster_indices);

    // 4. Get the clustering result and put it into the lidar frame.
    // get object from cluster_indices
    for (pcl::PointIndices cluster : cluster_indices) {
        if (cluster.indices.size() < euclidean_cluster_param_.min_point_number()) {
            continue;
        }
        // get cluster point index in cloud
        std::vector<int> point_idx;
        for (auto idx : cluster.indices) {
            point_idx.push_back(index_mapper_.at(idx));
        }
        base::Object object;
        object.confidence = 1.0;
        object.lidar_supplement.is_in_roi = true;
        object.lidar_supplement.num_points_in_roi = cluster.indices.size();
        object.lidar_supplement.cloud.CopyPointCloud(*frame->cloud, point_idx);
        object.lidar_supplement.cloud_world.CopyPointCloud(*frame->world_cloud, point_idx);
        // classification
        object.type = base::ObjectType::UNKNOWN;
        object.lidar_supplement.raw_probs.push_back(
                std::vector<float>(static_cast<int>(base::ObjectType::MAX_OBJECT_TYPE), 0.f));
        object.lidar_supplement.raw_probs.back()[static_cast<int>(object.type)] = 1.0f;
        object.lidar_supplement.raw_classification_methods.push_back(Name());
        // copy to type
        object.type_probs.assign(
                object.lidar_supplement.raw_probs.back().begin(), object.lidar_supplement.raw_probs.back().end());
        // copy to background objects
        std::shared_ptr<base::Object> obj(new base::Object);
        *obj = object;
        frame->segmented_objects.push_back(std::move(obj));
    }
    return true;
}

PERCEPTION_REGISTER_LIDARCLUSTER(EuclideanCluster);

}  // namespace lidar
}  // namespace perception
}  // namespace apollo
```

Define the euclidean_cluster.proto file in lidar_cluster/cluster/proto to specify the configuration items.

```bash
message EuclideanClusterConfig {
  optional float cluster_distance = 1;  // Distance threshold of Euclidean clustering
  optional int32 min_cluster_size = 2;  // Minimum cluster size
  optional int32 max_cluster_size = 3;  // Maximum cluster size
  optional int32 min_point_number = 4;  // Clusters with fewer points than this number are filtered out
};
```

Put the configuration of the clustering method in `lidar_cluster/data/euclidean_cluster.pb.txt`.

```bash
cluster_distance: 0.3
min_cluster_size: 1
max_cluster_size: 500
min_point_number: 3
```

Build the code:

```bash
buildtool build --gpu --opt
```

## Component usage

### Startup settings

First, modify the lidar_cluster_component.dag file in lidar_cluster/dag: change flag_file_path and delete conf/lidar_cluster_component.conf. Correct the dag file path in launch/lidar_cluster_component.launch.

```bash
module_config {
  module_library : "modules/perception/lidar_cluster/liblidar_cluster_component.so"
  components {
    class_name : "LidarClusterComponent"
    config {
      name : "lidar_cluster_component"
      config_file_path: "modules/perception/lidar_cluster/conf/lidar_cluster_component.pb.txt"
      flag_file_path: "/apollo/modules/perception/data/flag/perception_common.flag"  # Change the path to use the unified perception configuration
      readers {
        channel: "/perception/lidar/pointcloud_ground_detection"  # Input channel name
      }
    }
  }
}
```

Then, set the conf/lidar_cluster_component.pb.txt file,

```bash
name: "lidar-cluster"
output_channel_name: "/perception/lidar/cluster"  # Output channel name
plugin_param {
  name: "EuclideanCluster"
  config_path: "perception/lidar_cluster/data"
  config_file: "euclidean_cluster.pb.txt"
}
```

Finally, in lidar_output.dag, replace lidar_detection with lidar_cluster, and modify the input channel name of lidar_detection_filter.

```bash
module_config {  # Replace lidar_detect with lidar_cluster
  module_library : "modules/perception/lidar_cluster/liblidar_cluster_component.so"
  components {
    class_name : "LidarClusterComponent"
    config {
      name : "lidar_cluster_component"
      config_file_path: "modules/perception/lidar_cluster/conf/lidar_cluster_component.pb.txt"
      flag_file_path: "/apollo/modules/perception/data/flag/perception_common.flag"
      readers {
        channel: "/perception/lidar/pointcloud_ground_detection"  # Input channel
      }
    }
  }
}

module_config {
  module_library : "modules/perception/lidar_detection_filter/liblidar_detection_filter_component.so"
  components {
    class_name : "LidarDetectionFilterComponent"
    config {
      name : "LidarDetectionFilter"
      config_file_path : "/apollo/modules/perception/lidar_detection_filter/conf/lidar_detection_filter_config.pb.txt"
      flag_file_path: "/apollo/modules/perception/data/flag/perception_common.flag"
      readers {
        channel: "/perception/lidar/cluster"  # Receiving channel name of the components downstream of lidar_cluster
        pending_queue_size: 100
      }
    }
  }
}
```
