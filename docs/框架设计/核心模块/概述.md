### Perception

The perception module identifies the world around the autonomous vehicle. There are two important submodules in perception: obstacle detection and traffic light detection.

### Prediction

The prediction module predicts the future motion trajectories of the obstacles detected by perception.

### Routing

The routing module tells the autonomous vehicle how to reach its destination through a series of lanes or roads.

### Planning

The planning module plans the temporal and spatial trajectory of the autonomous vehicle.

### Control

The control module executes the trajectory produced by the planning module by generating control commands such as throttle, brake, and steering.

### CanBus

CanBus is the interface that passes control commands to the vehicle hardware. It also passes chassis information to the software system.

### HD-Map

This module is similar to a library. Instead of publishing and subscribing to messages, it is often used as query engine support to provide specific structured information about the road.

### Localization

The localization module uses information from GPS, LiDAR, and IMU devices to estimate the position of the autonomous vehicle.

### HMI (Human-Machine Interaction)

The human-machine interaction module, or DreamView in Apollo, is a module for viewing vehicle status, testing other modules, and controlling the vehicle in real time.

### Monitor

<!--The surveillance system of all the modules in the vehicle including hardware.-->

The monitoring system that monitors all software and hardware modules in the vehicle.

### Guardian

The functional safety module, used to intervene in failures detected by the Monitor module and take corresponding actions.

## Rich Autonomous Driving Algorithms

Apollo provides rich autonomous driving algorithms, covering the core autonomous driving technology stack, including perception, planning, control, and localization.

### Multi-Modal, Multi-View Perception Algorithms

- Visual traffic light recognition
- Visual lane line detection
- Visual obstacle recognition
- LiDAR point cloud obstacle recognition
- Multi-sensor fusion obstacle recognition
- Vehicle-road cooperative perception fusion

### Scenario-Based Planning Algorithms

- Public Road planner
- Lattice planner
- Navi planner
- RTK planner
- Model-based planner
- Model-based Open Space planner

### Precise Control Algorithms

- PID controller
- LQR controller
- MPC controller
- MRAC dual-loop controller

### Multi-Fusion Localization Algorithms

- RTK localization
- Multi-sensor fusion (MSF) localization
