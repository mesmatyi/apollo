# Distance Measurement

## Overview

Measure the distance between two points, or the total length of a polyline made up of multiple points. This can be used to determine the length of a route, calculate the distance between objects, determine the distance between two locations, and so on.

## Step 1: Install and Start Dreamview+

See [Play a Data Package](Apollo_alpha_doc/安装说明/软件包方式/快速上手/播放数据包.md).

## Step 2: Select a Simulation Scenario

In **Operations**, select **Sim_Control** or **Scenario_Sim**. This section uses **Sim_Control** as an example.

## Step 3: Select a Map and Vehicle

1. In **Environment Resources**, select a map. This section uses **San Mateo** as an example.

2. In **ADS Resources**, select a vehicle. This section uses **Mkz Example** as an example.

   > Note: Selecting a vehicle is optional.

3. In the **Vehicle Visualization** panel, click **Route Editing** to enter the route editing page.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_b3bef25.png)

   > Note: You can also skip opening route editing and directly click the distance measurement button at the lower right of the **Vehicle Visualization** panel.

4. In the **Vehicle Visualization** panel, click the distance measurement button ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_95d8c03.png).

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_4ee20d6.png)

5. In the editing interface, click a series of points, and double-click or right-click on the last point to finish. After the points are selected, the distance and angle to the previous point are displayed next to each point (except the first one).

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_352b5bb.png)

   Next to the last point, the ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_556beae.png) icon clears the sequence of coordinate points drawn this time.
