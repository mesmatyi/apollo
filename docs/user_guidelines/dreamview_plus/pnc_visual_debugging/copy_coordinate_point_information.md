# Copy Coordinate Point Information

## Overview

Select one or more coordinate points on the map, then copy them to the clipboard so that they can be used in other applications.

## Step 1: Install and Start Dreamview+

See [Play a Data Package](Apollo_alpha_doc/安装说明/软件包方式/快速上手/播放数据包.md).

## Step 2: Select a Simulation Scenario

In **Operations**, select **Sim_Control** or **Scenario_Sim**. This section uses **Sim_Control** as an example.

## Step 3: Select a Map and Vehicle

1. In **Environment Resources**, select a map. This section uses **San Mateo** as an example.

2. In **ADS Resources**, select a vehicle. This section uses **Mkz Example** as an example.

   > Note: Selecting a vehicle is optional.

3. In the **Vehicle Visualization** panel, click **Route Editing** to enter the route editing page.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_b3bef25.png)

   > Note: You can also skip opening route editing and directly click the copy coordinate point button at the lower right of the **Vehicle Visualization** panel.

4. In the **Vehicle Visualization** panel, click the copy coordinate point button ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_c5b09fe.png).

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_849fe3d.png)

5. In the editing interface, click to select a series of points; click to keep adding, and double-click or right-click to finish copying the coordinate points.

   ![aa33322853a77a1e6821c44cd60425ed.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/aa33322853a77a1e6821c44cd60425ed_aa33322.png)
