## Module Overview

### Functional Overview

The Planning module plays a vital role in an autonomous driving system. While obeying traffic rules, it navigates the vehicle from its current position along the routing path to the destination.

When planning a trajectory, Planning must meet three basic requirements:

- Obey road traffic rules, for example stopping to yield before a crosswalk, stopping when the traffic light is red and proceeding when it turns green,

- Not collide with other traffic participants encountered on the road, such as pedestrians, vehicles and fixed roadside obstacles,

- Ensure that the output trajectory, including path curvature, speed and acceleration, does not exceed the vehicle's execution capability limits.

At the same time, while meeting the basic requirements, the Planning module should also improve vehicle comfort as much as possible, avoiding uncomfortable situations such as abrupt acceleration or deceleration and overly rapid steering wheel angle changes.

### Workflow

Based on the perception information about the surrounding environment, the map, localization and navigation information, and the global path information input from upstream modules, the planning module plans a motion trajectory (including coordinates, speed, acceleration, jerk, time and other information) for the autonomous vehicle, and then passes this information to the control module.

### Module Principles

Apollo's planning module is implemented on a scenario-based basis. For different scenarios, the planning module completes trajectory planning by combining a series of independent tasks. Developers can adjust the list of scenarios the module supports, or the task types supported within a scenario, to meet their own needs.

![Module overview - module principles.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/%E6%A8%A1%E5%9D%97%E7%BB%BC%E8%BF%B0-%E6%A8%A1%E5%9D%97%E5%8E%9F%E7%90%86_2cf19d6.png)

The Apollo planning architecture is shown above. Some of the important components are as follows:

- Public Road Planner: implements a finite state machine that determines the driving scenario of the autonomous vehicle by combining navigation, environment and other information

- Scenario Manager: based on the state machine and vehicle-related information, invokes the Scenario appropriate for the current situation

- Scenario: combines information from upstream modules and completes trajectory planning for the autonomous vehicle through a series of task combinations

- Task combination: a set of tasks that implement decision and optimization. The optimizers are used to optimize the vehicle's trajectory and speed. The deciders, based on rules, determine driving behaviors of the autonomous vehicle such as when to change lanes, when to stop, when to creep (move slowly), or when creeping is complete.
