## Experiment Content

Sim Control is a simulation component provided by Dreamview+, Apollo's software interaction system. By simulating the inputs of Chassis, Localization, PerceptionObstacle and other information, it enables simulation and debugging of the planning algorithm module. This experiment introduces how to simulate and debug the vehicle cruise speed by modifying software parameters, so that developers learn how to use the Sim_Control component to debug Apollo software code.

## Experiment Objectives

- Become familiar with how to start the Apollo software system and master the use of the Dreamview+ interaction system,

- Become familiar with the workflow of the Apollo software system and master the use of the debugging tool Cyber_monitor,

- Master the method of simulating and debugging Apollo software code through the Sim_Control module.

## Practice Steps

### Step 1. Start the Simulation Environment

1. In the terminal, run the DreamView+ startup command. After it succeeds, click the Dreamview+ button in the menu bar to enter the Dreamview+ interface.
   
   ```bash
   aem bootstrap start --plus
   ```
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_38cab0c.png)
   
   The following interface indicates that Dreamview+ has started successfully.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_f34d264.png)

2. Open the **Mode Settings** panel in the left navigation bar, select **PnC** as the mode and **Sim_Control** as the operation to enter simulation mode.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_fdfc116.png)

3. Start the Planning module from the Modules list on the left.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_b6baf28.png)

4. Set the vehicle's simulated driving route.
   
   - Open the **Routing Editing** panel in the upper left corner of the **Vehicle Visualization** panel.
     
     ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_703a01e.png)
   
   - To specify an arbitrary starting point, first click **Initial Point**, then click a location on the map to specify the vehicle's starting position and heading.
     
     ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_10c9060.png)
   
   - Click **Waypoint**, then click the mouse to set the vehicle's driving route on the map (the last point is the end point). As shown in the figure below, three points are set: start point, waypoint, and end point.
     
     ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_d82fe15.png)
   
   - After the points are set, click **Save Editing** to return to the home page:
     
     ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_9859e44.png)
   
   - Click the run button in the bottom bar of the home page. As shown in the figure, the red line is the path found by the routing module on the map, and the light blue trajectory is the path planned in real time by the planning module. At this point, the observed cruise speed reaches a maximum of 40 km/h.
     
     ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_b441f7b.png)

### Edit the Code to Implement the Task

1. Open a new terminal window and enter the configuration parameter synchronization command. The system will automatically copy the configuration parameters of the planning module into the default directory of the profile.
   
   ```bash
   buildtool profile config init --package planning --profile=default
   ```

2. Enable the default directory as the directory where parameters take effect.
   
   ```bash
   aem profile use default
   ```

3. Use the online editor or vim to open the `planning.conf` file in the `/apollo_workspace/profiles/default/modules/planning/planning_component/conf` directory. `planning_upper_speed_limit` is the upper speed limit of Planning, and `default_cruise_speed` is the default cruise speed, in m/s (1 m/s = 3.6 km/h).
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_5ef882e.png)

4. Change the value of `default_cruise_speed` to 2. After saving, return to the simulation interface and restart the planning module (so that the system reloads the Planning parameters), resend the routing request, and click the start button at the bottom. The vehicle's cruise speed will now reach a maximum of 7 km/h.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_64ee33a.png)
   
   This concludes the experiment.
