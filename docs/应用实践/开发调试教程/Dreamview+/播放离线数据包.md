## Prerequisites

Complete the Dreamview+ plugin installation; see [Studio Plugin Installation](../应用实践/开发调试教程/Dreamview+/Studio%20插件安装.md).

## Procedure

You can quickly try offline data package playback through either package management or source code. The commands for entering the docker environment and starting dreamview+ differ between the two, so please follow the commands for your method.

### Step 1: Start and Open Dreamview+

You can start Dreamview+ through package management or from source. Choose one method and start Dreamview+ with the corresponding commands.

#### 1. Start Dreamview+

##### Method 1: Package Management

Enter the docker environment through package management, and run the following command in the docker environment to start Dreamview+:

```bash
aem bootstrap start --plus
```

> Note:
> 
> - If you want to stop Dreamview+, enter `aem bootstrap stop --plus`,
> - If you want to restart Dreamview+, enter `aem bootstrap restart --plus`.

##### Method 2: Source Code

Enter the docker environment from source, and run the following command in the docker environment to start Dreamview+:

```bash
bash scripts/bootstrap.sh start_plus
```

> Note:
> 
> - If you want to stop Dreamview+, enter `bash scripts/bootstrap.sh stop_plus`,
> - If you want to restart Dreamview+, enter `bash scripts/bootstrap.sh restart_plus`.

#### 2. Open Dreamview+

After it starts successfully, enter `localhost:8888` in the browser to open the Dreamview+ interface.

### Step 2: Play the Data Package

#### Play the Data Package in Dreamview+

After starting Dreamview+, enter the Dreamview+ interface. You can play the data package in the default mode or in another mode. This section uses the default mode as an example.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_7deb2d2.png)

1. Select **Default Mode**.

2. Check **Accept the User Agreement and Privacy Policy**, and click **Enter this Mode** to enter the **Mode Settings** page.

3. Download the data package.
   
   In **Resource Manager** > **Records**, first download the required data package **demo_3.5**.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_9_0/image_0b8f187.png)

4. Click the play button in the bottom area.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_9_0/image_45acc2d.png)
   
   You can see the data package playback in **Vehicle Visualization**.

#### Play the Data Package from the Command Line

1. Enter the docker environment,

2. In Dreamview+, under **Resource Manager** > **Records**, first download the required data package. Enter the following command to play the data package:
   
   ```bash
   cyber_recorder play -f ~/.apollo/resources/records/demo_3.5 -l
   ```

> Note: If you want to play the data package in a loop, add -l; if you do not want to loop it, you do not need to add -l.
