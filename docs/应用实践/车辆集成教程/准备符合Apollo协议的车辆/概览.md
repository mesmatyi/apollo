The Apollo new-vehicle adaptation method described in this document helps developers quickly bring in a new vehicle so that they can develop software on Apollo. The drive-by-wire signal standards and requirements described here all come from the Apollo Open Vehicle Certification Platform.

The vehicle certification platform currently includes vehicle models such as Lincoln, Lexus, GE3 and WEY.

- If you have a vehicle and are willing to adapt the Apollo code for autonomous driving tests, please follow the drive-by-wire requirements in the document to become familiar with and prepare the vehicle's low-level control protocol and carry out the related verification tests. For more details, see [Apollo Open Vehicle Certification Platform](http://developer.apollo.auto/vehicle/certificate_cn.html).

- If you do not have a vehicle, you can choose one of the vehicles we have already adapted for autonomous driving tests.

This document mainly describes **how to add a new vehicle that conforms to the Apollo standard in Apollo**, so that developers can design a chassis system that meets Apollo's drive-by-wire requirements, develop chassis adaptation code for the Apollo software, and build the ability to quickly connect to the Apollo software.

When adapting the CAN communication of a new vehicle, developers first need to design a chassis communication protocol that meets Apollo's drive-by-wire requirements. This part builds a DBC file of the vehicle chassis signals according to the Apollo drive-by-wire list, designing the chassis-related interface definitions, with messages and signals corresponding one-to-one to the DBC. After the DBC file is designed, use the DBC conversion code tool provided by Apollo to obtain the first version of the underlying canbus adaptation code, then add the control logic of the vehicle in question, building the vehicle's underlying chassis signals and the signals for controlling the vehicle in Apollo. Finally, debug and verify the signals with the canbus debugging tools to make sure the vehicle's chassis signals communicate with the upper layers of Apollo without any problems.
