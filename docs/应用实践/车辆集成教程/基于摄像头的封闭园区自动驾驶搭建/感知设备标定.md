This user manual aims to help users complete the calibration of the camera (Camera-Lidar).

## Prerequisites

1. Complete [Record-and-Replay Setup -- Vehicle Record-and-Replay Demonstration](../应用实践/车辆集成教程/循迹搭建/车辆循迹演示.md).

2. Complete [Camera-Based Closed-Campus Autonomous Driving Setup -- Perception Device Integration](../应用实践/车辆集成教程/基于摄像头的封闭园区自动驾驶搭建/感知设备集成.md).

## Step 1: Register for Baidu Cloud Object Storage (BOS)

For the registration method, see [Baidu Cloud Object Storage BOS Registration and Basic Usage Guide](https://apollo.baidu.com/Apollo-Homepage-Document/Vehicle_Nameplate/三、开通Fuel云服务/2.%20开通百度云BOS).

Please contact the business department to activate a cloud service account. You need to provide the `Bucket Name`, `Region` and user email information registered in the previous step.

#### Manually Measure the Camera-Lidar Initial Extrinsic File

It is assumed here that the user has installed the sensors correctly as required by the perception device integration document, that is, the sensor coordinate system definitions are the same as those above and the installation error meets the requirements in the document.

- rotation: when the sensor installation meets the requirements of the perception device integration document, this value does not need to be measured, and the following default value can be used directly.
  
  ```yaml
  rotation:
    w: 0.5
    x: -0.5
    y: 0.5
    z: -0.5
  ```

- translation: you need to manually measure the displacement transformation with the Lidar coordinate system as the base coordinate system and the Camera coordinate system as the target coordinate system. An example of a Lidar-Camera displacement transformation is shown below:
  
  ```yaml
  translation:
    x: 0.67
    y: -0.1
    z: -0.64
  ```

### 2. Sensor Intrinsic Calibration

The intrinsics include the camera's focal length, principal point, distortion coefficients and other information, and can be obtained with mature camera calibration tools, for example: [ROS Camera Calibration Tools](http://wiki.ros.org/camera_calibration/Tutorials/MonocularCalibration) and [Camera Calibration Toolbox for Matlab](http://www.vision.caltech.edu/bouguetj/calib_doc/).

## Step 5: Collect Data with Fuel-Client

> Note: When Fuel-Client collects Camera-Lidar calibration data, make sure that only the camera whose calibration data is to be collected is working; it is recommended to unplug the USB plugs of the other cameras first. Calibrating multiple cameras requires collecting data in multiple separate passes.

### 1. Select the Correct Mode and Vehicle Model

1. Select the `Camera-Lidar Sensor Calibration` mode.

2. Select the correct vehicle model according to the actual situation.

![1.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_6_0/1_ca99842.png)

### 2. Start Fuel Client and Start the Corresponding Modules

1. Under the `Tasks` tab of DreamView, turn on `Sim Control`.
2. Turn on `Fuel Client`.
   
   > Note: After `Fuel Client` is turned on, be sure to turn off `Sim Control`.
   > ![1.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_6_0/1_d9fae91.png)
3. Under the `Module Controllers` tab of DreamView, start the `Camera`, `GPS`, `Lidar` and `Localization` modules. When `Camera`, `GPS`, `Lidar` and `RTK` in the module status display on the left are all green, the modules have started successfully.
   
   > Note: After Localization starts, wait 1 to 2 minutes before it outputs data normally.

![1.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_6_0/1_faf6d59.png)

### 3. Start the Recorder Module and Begin Collecting

1. When `Camera`, `GPS`, `Lidar` and `RTK` in the module status display on the left are all green, turn on the Recorder module and begin collecting data. While recording, remotely drive the vehicle slowly in a straight line: drive for 10 seconds, then stop for 5 seconds, and repeat this 5 times.

2. After the data collection is complete, turn off the `Recorder` module to stop recording.

> Note: Calibrate when lighting conditions are good. The site must be a straight road with static reference objects such as buildings and vehicles on both sides of the road; avoid too many dynamic obstacles and avoid strong backlight.

## Step 6: Preprocess the Data with Fuel Client

![1.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_6_0/1_046e9df.png)

1. Click `Configuration` in the upper right corner to enter the preprocessing interface.

2. Fill in the measured initial extrinsics.

3. Fill in the `D` and `K` matrix parameters of the intrinsics.

4. Click **Preprocess** to preprocess.
   
   Wait for the preprocessing to finish; the message `Data extraction is completed successfully!` indicates that preprocessing is complete.

5. Save the generated preprocessed files. Switch to the `apollo/output/sensor_calibration/camera_to_lidar/extracted_data/` directory and save the `camera_to_lidar-xxx` file in that directory (`xxx` is the time the data package was recorded). Here and below, `camera_to_lidar-2021-01-12-13-49` is used as the example.

## Step 7: Generate the Extrinsic File with the Calibration Cloud Service

### 1. Upload the Preprocessed Data to BOS

> Note: You must use a bucket that has been granted permission. Confirm that the `Bucket Name` and `Region` are consistent with the Bucket name and region submitted when registering with the business department.

Upload the `camera_to_lidar-2021-01-12-13-49` directory to the root directory of BOS, to serve as the `input data path` from which the subsequent cloud calibration service reads data.

### 2. Submit the Cloud Calibration Task

1. Open the Apollo cloud service page.

2. Click **Apollo Fuel** > **Tasks**.

3. Click **New Task**.

![fuel_new_task](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo-D-KIT/78f28add5ffcca20b38b547db16292b1.png)

4. Select the **Perception Calibration** option from the drop-down box.
   
   - Fill in the **Input Data Path** according to the actual situation; `camera_to_lidar-2021-01-12-13-49` is used as the example here.
   - Specify the **Output Data Path**.

5. Click **Submit Job**.

![sensor_calibration_fuel](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo-D-KIT/fd6b2d735012fe35b66f50ea4447576d.jpg)

### 3. Obtain the Calibration Result Verification and the Calibration Extrinsic File

After the cloud calibration task completes, you will receive a calibration result email in your registered mailbox. If the calibration task succeeds, it will contain the calibration extrinsic file.

**Camera-Lidar Calibration Result Verification**:

The `output data path` specified by the user in BOS contains the calibration result verification images. In the generated point cloud projection image, look for objects and markers with clear edges and check how their edge contours align. If, for targets within 50 meters, the point cloud edges and the image edges coincide, the accuracy of the calibration result is high. Conversely, if misalignment appears, the calibration result contains errors. When the error exceeds a certain range (the range depends on the actual use case), the extrinsics are not usable.

- The figure below shows the point cloud projection with accurate extrinsics
  
  ![camera_calibration_result_picture1](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo-D-KIT/13f62d6c0ceadd8e8979d34908d54b8d.jpg)

- The figure below shows the point cloud projection with biased extrinsics
  
  ![camera_calibration_result_picture2](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo-D-KIT/0e2aa8f94a4286defd2965fcf01d0edf.jpg)

**Camera-Lidar Calibration Extrinsic File**:

After confirming that the extrinsic file obtained from the email is reasonable, do the following:

- For the 6mm camera, rename the calibrated intrinsic file to `front_6mm_intrinsics.yaml` and replace the file in the `modules/calibration/data/车型目录/camera_para/` directory; replace the `rotation` and `translation` values in `modules/calibration/data/车型目录/camera_params/front_6mm_extrinsics.yaml` with the `rotation` and `translation` values from the calibrated extrinsic file. Be careful not to modify `frame_id`.

- If calibrating the 12mm camera, you need to modify the two files `front_12mm_intrinsics.yaml` and `front_12mm_extrinsics.yaml` in the `modules/calibration/data/车型目录/camera_para` directory.

- By default 1 6mm camera and 1 12mm camera are used. If you need to use a second 6mm camera, you need to specify the file names yourself and make the corresponding modifications.

## FAQ

### After running the Sensor Calibration task, the email says the task failed

It is recommended to check whether the input path is correct.

### The calibration result has a large error

- During calibration, make sure the GNSS signal status is good and there are static obstacles with clear outlines around.

- Ensure the installation accuracy of the sensors; when the installation error exceeds the required accuracy, the calibration result does not converge easily.
