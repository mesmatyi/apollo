This document uses a Lincoln MKZ that has completed drive-by-wire modification as an example to describe how to integrate and install the hardware system of an Apollo autonomous vehicle.

You can learn how to integrate and install the cameras, LiDAR, inertial navigation system, and the Hardware 3.0 computing unit on the vehicle. The sensors integrated this time are Hardware 3.0 (HW 3.0), the Expansion Box (EP), a LiDAR, the PP7 inertial navigation system, 2 millimeter-wave radars, and 2 cameras.

The electrical architecture topology of the hardware integrated this time is as follows:

![Topology diagram](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo_Doc_CN_6_0/4735b0c6c902387bc6e33496a15a0097.png)

> Note: This document focuses on the electrical integration of the hardware sensors. Hardware installation only shows installation positions, and you can integrate according to your own vehicle. The integration is also explained in the order of sensor integration, which does not represent the actual order of hardware installation steps.

## Prerequisites

To complete the hardware integration on the Lincoln MKZ, you need to understand the following in advance:

- The basic functions and interface types of the LiDAR, cameras, and integrated navigation system,

- Have the sensors supported by the Apollo autonomous driving system ready. For details, see [Apollo Hardware Development Platform](https://developer.apollo.auto/platform/hardware_cn.html),

- Basic knowledge of electrical engineering and communication.

## Hardware Integration and Installation

The hardware devices of the Lincoln MKZ are installed in two places. One is the fixed aluminum plate in the trunk, where Hardware 3.0, the Expansion Box, and the battery are installed; the other is the roof bracket, where the LiDAR, cameras, millimeter-wave radars, and GNSS antennas are installed.

> Note: The fixed aluminum plate and the roof bracket are customized by Baidu according to the Lincoln MKZ's structure and the installed hardware devices. Developers can design their own fixed aluminum plate and roof bracket according to their own vehicle and installed devices.

## Electrical Integration and Installation

### Hardware 3.0 Integration and Installation

The computing unit that Baidu provides for the Lincoln MKZ autonomous vehicle is Baidu's self-developed Hardware 3.0. Hardware 3.0 integrates CPU and GPU modules. It can also provide 12V DC power and various sensor interfaces for external sensors, such as LiDAR interfaces and camera interfaces.

The hardware interfaces of Hardware 3.0 are as follows:

- Front of Hardware 3.0:
  
  The front of Hardware 3.0 has a power button, 2 NVME data disks, and the Hardware 3.0 status indicator.

![Hardware 3.0](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo_Doc_CN_6_0/523c3d9cf4c48fab5cf351363a5a7414.png)

- Back of Hardware 3.0:
  
  The back of Hardware 3.0 has the system power interface, which supplies power to Hardware 3.0; the sensor power interface, which supplies 12V power to external sensors; and the remote power-on switch, which is used to power Hardware 3.0 on and off from the driver's cabin.

![Back of Hardware 3.0.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_6_0/HW3.0%E8%83%8C%E9%9D%A2_28a20f1.png)

- Left side of Hardware 3.0:

![Left side of Hardware 3.0.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_6_0/HW3.0%E5%B7%A6%E4%BE%A7_b0c3367.png)

Interfaces on the left side of Hardware 3.0:

1. EXPANSION interface, which can be connected to the external Expansion Box through MiniSAS HD cables;

2. EXT GPS interface, used to connect the GPRMC and PPS signals of the PP7;

3. LIDAR16/32 M2 interface, used to connect the LiDAR;

4. LIDAR16/32 64 interface, used to provide GPRMC and PPS signals to external sensors, with 3 groups of signals available in total;

5. 8 channels of 1000M Ethernet interfaces, used to connect external LiDAR sensors or other devices;

6. SFP+ interface, used to communicate the information of the NVME data disks with the server through this interface;

7. WIFI antenna interface, used to provide an antenna for the internal WIFI module;

8. 4G/LTE antenna interface, used to provide an antenna for the internal 4G module.
- Right side of Hardware 3.0:

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_6_0/image_ece7015.png)

Interfaces on the right side of Hardware 3.0:

1. CPU1 interfaces: including a monitor VGA interface, 2 USB2.0 interfaces, and 1 audio output interface;

2. 24 Pin CAN interface, through which a total of 8 CAN channels can be brought out;

3. 10 Fakra camera interfaces, used to connect external cameras;

4. CPU2 interfaces: including 2 USB2.0 interfaces, 1 audio interface, and a monitor DVI HDMI interface;

5. 2 USB interfaces (console interfaces), which are system serial ports used for debugging.

### PP7 Inertial Navigation System Integration and Installation

The inertial navigation system is part of the localization of the autonomous vehicle; it integrates a GNSS receiver board and an inertial IMU sensor. The Lincoln MKZ autonomous vehicle uses the Novatel PP7 device, as shown.

![PP7](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo_Doc_CN_6_0/a2787939dbba777ec1b290b49cafad8a.jpg)

The NovAtel PwrPak7 (PP7) is a scalable, high-precision GNSS receiver with integrated GNSS and INS hardware, providing an easy-to-deploy GNSS+INS system. The PP7 uses a high-precision receiver card to provide scalable high-precision positioning, and uses an Epson G320N IMU to provide accelerometer and gyroscope measurements.

The main interfaces of the inertial navigation unit are:

- Power interface: supplies power to the PP7 device;

- Time-synchronization output interface: outputs precise time for synchronizing with other devices;

- Data interface: provides data output externally, and can be configured to use either the Ethernet port or the USB interface.

#### PP7 Hardware Integration and Installation

1. Install the PP7 in the trunk of the Lincoln MKZ, at the middle position of the rear axle.

2. Install the two satellite antennas in the mounting holes at the rear of the roof bracket.

![PP7 installation](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo_Doc_CN_6_0/efacf425f82a329a2e273f113b59ae02.png)

### Millimeter-Wave Radar Integration and Installation

The CAN of Hardware 3.0 is brought out through the 24 pin CAN interface in the right-side view. Hardware 3.0 provides 8 CAN channels, of which 4 are for radar (corresponding to 0/1/2/4), 2 are for the vehicle body CAN (3/7), and the other 2 are reserved. The vehicle body CAN uses CAN0 by default, which corresponds to the connection CAN3; CAN7 corresponds to CAN1 in software.

The Lincoln MKZ autonomous vehicle has two Continental ARS 408-21 millimeter-wave radars installed. The ARS408-21 is the newest high-end product in Continental's 40X millimeter-wave radar sensor series and is suitable for different application scenarios. The ARS408-21 resolves the conflict between measurement performance and high safety well: it can detect the distance to targets in real time and judge whether there is a collision risk based on the current vehicle speed; it has an automatic fault detection function that can identify sensor problems and automatically output fault codes; and its lightweight design provides good robustness.

![radar](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo_Doc_CN_6_0/7b7270b6f25ad76f523d30334a7788b4.png)

![radar](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo_Doc_CN_6_0/841fbfdc9e00ad239e62eddd6f887b62.png)

#### Millimeter-Wave Radar Hardware Integration and Installation

Install the two millimeter-wave radars at the front of the vehicle and at the rear of the roof bracket, respectively.

> Note: The LiDAR is installed facing upward, and the front millimeter-wave radar requires an additional mounting bracket.

#### Millimeter-Wave Radar Electrical Integration and Connection

Use the millimeter-wave radar wiring harness to connect the millimeter-wave radars to the can0 and can1 interfaces of the customized harness for the Hardware 3.0 CAN interface.

> Note: This harness is customized. Please connect according to the actual situation. For the harnesses provided with this document, there are two: one is Hardware 3.0 to DB9 (providing the CAN bus interface), and the other is the harness that connects the integrated millimeter-wave radar unit.

### 4G Router Integration and Installation

The Apollo autonomous vehicle uses RTK-based GNSS positioning, which needs to connect to the external network to receive base station information, so a network connection is required. For the Lincoln MKZ, Baidu provides a 4G wireless router with a 4G IoT card inserted to provide connectivity to the external network.

![4Grouter](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo_Doc_CN_6_0/11bdae920fdc6d7d9bd82206450e6188.png)

#### 4G Router Hardware Integration and Installation

Install the 4G router at a suitable position in the trunk. If there is an antenna, bring the antenna out and install it at a suitable position on the roof bracket.

#### 4G Router Electrical Integration and Installation

1. Connect the router power connector on the sensor wiring harness to the router's power port.

2. Use an Ethernet cable to connect the 4G router's Ethernet port to Ethernet port 1 of Hardware 3.0.

![4Grouter wiring](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo_Doc_CN_6_0/8d50d6a556c1797a4257b03edbcef0a4.png)

![4Grouter wiring](https://bce.bdstatic.com/p3m/Apollo-Homepage-Document/images/Apollo_Doc_CN_6_0/2760d8ab38feffcd85f8e202f7efcf9c.png)

> Note: When using it, make sure the IoT card has been activated correctly and installed in the 4G router.
