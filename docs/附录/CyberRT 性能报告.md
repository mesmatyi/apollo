## Introduction

This performance report aims to compare the results of various performance metrics of the old and new versions of CyberRT for cross-process / cross-machine transmission under different transmission conditions, and to list detailed data on the transmission metrics when using different modules / different sensors (business modules, standard-spec sensors, high-spec sensors, and ultra-high-spec sensors). All results of this test were generated by the cyber_benchmark benchmarking tool.
