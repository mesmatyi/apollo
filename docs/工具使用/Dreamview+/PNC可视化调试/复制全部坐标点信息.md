## Overview

Select one or more coordinate points on the map and copy them to the clipboard, so that they can be used in other applications.

## Step 1: Install and Start Dreamview+

See the [Package Management Installation](../安装指南/包管理安装方式.md) document.

## Step 2: Select the Simulation Scenario

In **Operations**, select **Sim_Control** or **Scenario_Sim**. This section uses **Sim_Control** as an example.

## Step 3: Select the Map and Vehicle

1. In **Environment Resources**, select a map. This section uses **San Mateo** as an example.

2. In **ADS Resources**, select a vehicle. This section uses **Mkz Example** as an example.

   > Note: Selecting a vehicle is optional.

3. In the **Vehicle Visualization** panel, click **Routing Editing** to enter the route editing page.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_b3bef25.png)

   > Note: You can also skip opening Routing Editing and directly click the copy-coordinates button at the lower right of the **Vehicle Visualization** panel.

4. In the **Vehicle Visualization** panel, click the copy-coordinates button ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_c5b09fe.png).

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_849fe3d.png)

5. In the editing interface, click to select a series of points. Click to keep adding points; double-click or right-click to finish copying the coordinates.

   ![aa33322853a77a1e6821c44cd60425ed.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/aa33322853a77a1e6821c44cd60425ed_aa33322.png)
