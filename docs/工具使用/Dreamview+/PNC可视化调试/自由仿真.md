## Overview

Used to run and monitor the performance of planning and control algorithms. You can enable or disable the planning, control and record-and-replay algorithms and add driving trajectories. While running, you can view module latency and console logs, view the data records of the PnC algorithms through the monitor module, and inspect the message contents in each channel.

## Step 1: Install and Start Dreamview+

See the [Package Management Installation](../安装指南/包管理安装方式.md) document.

## Step 2: Select the Mode

1. Select **Mode Settings** in the left navigation bar.

2. In **Mode**, select the **PnC** mode.

3. In **Operations**, select **Sim_Control**.

## Step 3: Select the Map and Vehicle

1. In the **Environment Resources** > **HDMap** list, select a map. This section uses **Sunnyvale Loop** as an example.

2. In **ADS Resources**, select a vehicle. This section uses **Mkz Example** as an example.

> Note: Selecting a vehicle is optional.

## Step 4: Enable the Modules

Enable the **Planning** and **Prediction** modules.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_92a573f.png)

## Step 5: Draw a Trajectory

Edit the driving trajectory/route. See the document [Trajectory Drawing](./轨迹绘制.md).

## Step 6: Run the Simulation

Click the play button in the bottom bar to run the simulation.

## Step 7: View the Data

1. Add the PnC Monitor, Module Delay and Console panels.

2. Open the PnC Monitor to view the planning and control data.

3. View the Channel information, module latency and console information.

## Step 8: Debug and Modify the Code

You can debug and modify the code according to the planning results.
