## Overview

Used to run and monitor the performance of planning and control algorithms. You can enable or disable the planning, control and routing algorithms, sync scenarios from the cloud and run them, and add different driving trajectories to a scenario. While running, you can view module latency and console logs, view the data records of the PnC algorithms through the monitor module, and inspect the message contents in each channel.

## Step 1: Install and Start Dreamview+

See the [Package Management Installation](../安装指南/包管理安装方式.md) document.

## Step 2: Select the Mode

1. Select **Mode Settings** in the left navigation bar.

2. In **Mode**, select the **PnC** mode.

3. In **Operations**, select **Scenario_Sim**.

## Step 3: Download a Scenario Set

1. Select **Resource Manager** in the left navigation bar.

2. Click **Scenarios** and download the required scenario set from the Apollo Studio cloud.

3. Click **Mode Settings** > **Environment Resources** > **Scenarios**, and select the scenario to run from the local scenario list.

## (Optional) Step 4: Select a Vehicle

In **ADS Resources**, select **Vehicle**.

## Step 5: Enable the Modules

In **Modules**, enable the **Planning** and **Prediction** modules.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_e21b23e.png)

## Step 6: Draw a Trajectory

1. In the **Vehicle Visualization** panel, click **Routing Editing**.

2. Click the ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_4d04326.png) icon to add the start point.

3. Click the ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_a559070.png) icon to add trajectory points. When the drawing is complete, click **Save Editing**.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_804891a.png)

## Step 7: Run the Simulation

Click the play button in the bottom bar to run the simulation.

## Step 8: View the Data

1. Click **Add Panel** in the left navigation bar.

2. Add the **PnC Monitor**, **Module Delay** and **Console** panels to view module latency and console information.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_alpha_doc/image_ea6a228.png)

## Step 9: Debug and Modify the Code

Debug the code according to your own needs.
