## Mode

In Mode, you can select the mode you want to use, including the default mode, perception development mode, and so on.

### Switch Modes

Select the desired mode from the drop-down list:

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_9_0/image_92fca84.png)

- For playing data packages in the default mode, see [Play a Data Package](Apollo_alpha_doc/安装说明/软件包方式/快速上手/步骤三：播放数据包.md).

- For playing data packages in perception mode, see [How to Play a Data Package in Perception Mode](<Apollo_alpha_doc/应用实践/上机实践教程/Apollo 感知实践（2.0）/如何在感知模式下播包.md>).

## Modules

Modules include localization, perception, record-and-replay, recording and other modules, used together with different modes.

### Enable One or More Modules

Move the slider to the right:

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_9_0/image_0ca8aea.png)

### Disable One or More Modules

Move the slider to the left:

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_9_0/image_1143b0e.png)

### Enable All Modules with One Click

Click **Setup All**.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_9_0/image_02bb918.png)

### Disable All Modules with One Click

Click **Reset All**.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_9_0/image_cad7176.png)

## Current Resources

Displays the resources currently in use, including data packages, maps, scenarios, vehicles, and so on.

## Environment Resources

Environment resources include Records, HDMap and other resources, where:

- **Records**: data packages, including all the data packages that have been downloaded in **Resource Manager**,
  
  <!-- **Scenarios**: simulation scenarios, an overall dynamic description of the comprehensive interaction process, within a certain time and space range, between the autonomous vehicle and other vehicles, roads, traffic facilities, weather conditions and other elements in the driving environment.-->
- **HDMap**: HD map.

### Sync Cloud Apollo Studio Data Packages to the Local Machine

1. Sync your account through the Studio plugin. For detailed steps, see the guide under **Personal Center** > **Login** at the lower left (skip this step if you are already logged in).

2. Click **Resource Manager** in the left navigation bar.

3. Under **Records**, select the content to sync, click the download button in the operation bar on the right, and close **Resource Manager** after the download is complete.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Doc_CN_9_0/image_807fe72.png)

4. The downloaded data package can be found in **Environment Resources** on the main interface.
