## Overview

Map editing means annotating, on the point cloud base map, the HD map information required by the algorithms, such as lanes, sidewalks and intersections.

## Procedure

### Step 1: Open the Base Map

1. Go to the map editing interface and click **File** > **Open Base Map**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_17f3a37.png)

   > Note: The Chrome browser is recommended for map editing, and multiple browsers can access it at the same time.

2. Select the base map you want to edit and click **Open** to finish loading the base map.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_aa42e14.png)

   After the base map is loaded, follow the steps below to draw on it.

### Step 2: Edit the Base Map

For detailed operations on drawing elements such as lines, lanes, intersections, crosswalks, speed bumps, traffic lights and parking spaces, see the map editing chapter.

### Step 3: Save the Base Map

1. In the **File** drop-down list, select **Save**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_159783d.png)

2. Enter a file name and click **Save** to finish saving the annotated map.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_4c9e4f3.png)

### Step 4: Publish the Base Map

1. In the **File** drop-down list, select **Publish**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_e244bbd.png)

2. Enter a file name and click **Save** to finish publishing the annotated map.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_9abda2c.png)

   > Notes:
   > - Save: means the user can edit the map to be modified multiple times; it is saved under the `data/editor_map` path.
   > - Publish: means the map used by autonomous driving; after publishing it is saved under the `data/map_data` path, and the published map provides the map file for autonomous driving.

## View-Related Operations

### Zoom the Background In/Out

- Windows: mouse wheel; scroll forward to move closer (zoom in) and backward to move away (zoom out).
- Mac OS: place two fingers on the trackpad, then spread them apart to zoom in on the view, or move them together to zoom out.

### Move the View

- Windows: right-click and drag.
- Mac OS: drag with two fingers on the trackpad.

### Rotate the View

- Windows: hold the ALT key and drag horizontally with the left button.
- Mac OS: hold the option key and drag horizontally with one finger on the trackpad.

### Rotate an Element
First click to select an element such as a line, lane, intersection or crosswalk. The element is highlighted and a rotate button appears around it. Click the rotate button to rotate left/right or counterclockwise/clockwise.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_6c6b6a8.png)

### Move an Element

First click to select an element such as a line, lane, intersection or crosswalk. The element is highlighted. Then press and hold the left mouse button again and drag to move the element.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_5c40f94.png)

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_42418c5.png)

### Connect Elements

Hold the Shift key to select multiple elements you want to connect at the same time, such as lines or lanes, and click the corresponding connect button, for example connecting lines to generate a lane, or connecting lanes.

### Select Multiple Elements

Click to select the first element, then hold the Shift key and select the second element.

> Note: The multi-selected elements must be of the same type; otherwise they cannot be selected.
