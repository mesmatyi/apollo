## Draw a Speed Bump

1. Click the **Speed Bump** button at the top.

2. Click the first point on the base map to determine the start point of the speed bump.

3. Click the second point to determine the end point of the speed bump, completing the speed bump.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_5a1615e.png)

## Move a Speed Bump

1. Select the speed bump you want to move.
2. Drag with the mouse to move the speed bump.

## Delete a Speed Bump

1. Select the speed bump you want to delete.

2. Press the Delete key to delete the speed bump.
   
   - On Windows, press the Delete key.
   - On MAC OS, press fn + Delete.
