## Add a Barrier Gate

1. Click the **Barrier Gate** button.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_2210143.png)

2. Click one side of the selected lane to create the start point of the stop line, and click the other side of the selected lane to create the end point of the stop line, creating a stop line.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_898cd7a.png)

3. A barrier gate is created along the lane direction at a certain distance from the stop line (default length 2.5 m), with the barrier gate aligned with the midpoint of the stop line.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_96f5b1e.png)
   
   ## Move a Barrier Gate

4. Click to select the barrier gate.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_a3cf089.png)
   
   After selection, the barrier gate turns blue.

5. Move the stop line and the barrier gate to the specified position.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_503851a.png)

## View a Barrier Gate

1. Click to select the barrier gate.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_a3cf089.png)

2. View the property information on the right.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_d6e5e30.png)
   
   ## Change Barrier Gate Properties

3. Click to select the barrier gate.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_a3cf089.png)

4. Modify the property information on the right.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_d6e5e30.png)
   
   ## Delete a Barrier Gate

5. Click to select the barrier gate.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_a3cf089.png)

6. Press the **Delete** key to delete the barrier gate; the associated stop line is deleted as well.
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_05812bf.png)
   
   - On Windows, press the **Delete** key.
   - On MAC OS, press **fn** + **Delete**.
