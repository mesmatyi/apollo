## Product Description

The map tool can quickly build high-precision maps for testing and verifying the performance of autonomous driving algorithms on a real vehicle. Through detection by the collection algorithm, information about the surrounding environment is obtained and a point cloud base map is generated that can serve as a reference for drawing. Road elements such as lanes, traffic lights and parking spaces are then drawn with the base map as a reference to generate map files, which finally serve as data input for the algorithms and the autonomous driving system. This reduces the difficulty of field testing and shortens debugging and adaptation time.

## Feature Overview

### Map Collection

Using LiDAR and mapping algorithms, the point cloud data detected in the field is aggregated into a point cloud map, intuitively visualizing the surrounding geographic environment. Two modes are supported: RTK mapping and Slam mapping.

### Map Editor

- Supports drawing elements such as straight roads, curves, crossroads, traffic lights, parking spaces and sidewalks;
- Supports modifying detailed attributes such as lane length and width, direction, speed limit, curve curvature, and predecessor/successor relationships;
- Supports modification and iteration, and can be published in the Apollo HD map format for simulation or field road testing.

## Glossary

- Base map (basemap): a point cloud map file output after aggregating and processing environment data collected by the LiDAR and GNSS sensors on the vehicle. It can be used as a reference for drawing maps, making the drawn map content more accurate.
- Map (HDmap): an HD map file format that can be used as a reference for perception and PnC algorithms, with semantic information such as lanes, sidewalks, crossroads, traffic lights and parking spaces, as well as the structural relationships between them.
  Editing map: an editable map storage format that supports multiple edits and saves.
