## Overview

Use simulation to verify the usability of the map.

## Procedure

1. Edit and publish the map.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_f09d0ea.png)

2. Edit the name of the published map and click Save.

3. Restart Dreamview+.
   
   ```bash
   aem bootstrap  restart --plus
   ```
   
   > Note: If Dreamview+ and the map tool are not in the same docker container, you need to copy the map file to the directory in the docker container where Dreamview+ runs.

4. In **Mode**, select the PNC mode, and in **Operations**, select **Sim_Control**.

5. In the **Environment Resources** > **HDMap** resources, select the map file you just published; it loads successfully.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_40002e0.png)

6. Click **Routing Editing**.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_a6a46c0.png)

7. Set the start point and end point of the ego vehicle, and click **Save Editing**.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_11d3eab.png)

8. Return to the home page and click **START** to view the simulation results.
   
    ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Beta_Doc/image_3464bdf.png)
   
   If the vehicle runs along the Routing and Running trajectory lines, the map is usable.
