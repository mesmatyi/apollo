This section uses an activation application as an example to describe how to apply for the calibration tool. You can also submit a free trial application and use the tool after approval.

> Note: An activation application is for customers who have purchased the calibration tool, and is submitted based on the purchase contract number and service content. It is currently open to organization accounts.

## Prerequisites

- The authentication tool has been installed. Run the authentication tool installation command outside the docker environment. For details, see the document [Apollo Software Installation](https://apollo.baidu.com/community/Apollo-Homepage-Document?doc=BYFxAcGcC4HpYIbgPYBtXIHQCMEEsATAV0wGNkBbWA5UyRFdZAWnAQCcBrZgcwFMAdn3Z5SsVAhB9IIWBQIB9GnQUAmBQA8AogDZNATgDMmgBwARTVoAsmgEIWN+gMKW9jtyYDsrzQEEAjH7G6tomdg6+AGKWNhq2tnZuWvqmxhq+YQBmAAwmhqQEngCs+kb62dhF-pl8pNl8mapWfPVF9fWYoBSoQA) > **Environment Tool Installation** > **Authentication Tool Installation** section.

- Make sure the lidar and camera hardware drivers are installed, so that the camera and lidar can start normally when you open Dreamview+ for calibration.

## Step 1: Apply to Activate the Service

1. Log in to the [Apollo Developer Community](https://apollo.baidu.com/).

2. In the menu bar, select **Products** > **Development Tools** > **Map and Calibration**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_00474f7.png)

3. Select the workspace identity and click **Confirm**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_6419eb4.png)

4. On the **Map and Calibration** application page, click **Activation Application**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_353bee1.png)

   > Note: The calibration feature requires an application. Whether you choose the free trial or the activation application, you must wait for approval by the relevant personnel before you can use it.

5. On the **Activation Application** page, edit the tool type and other related information of the application and click **OK**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_0e68cdc.png)

   It shows that the calibration tool application succeeded.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_61144e1.png)

   After applying, it shows that the service you applied for is under approval; please wait patiently for approval. After approval is granted, return to Configuration Management to complete the tool activation described below.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_5e45d98.png)

## Step 2: Activate the Service

1. In **Configuration Management**, select the **Calibration Tool** tab.
2. Click **Activate**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_a5a5ee7.png)

3. Click **Confirm**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_73e9fb0.png)

   It shows that the calibration tool was activated successfully.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_bbb0937.png)

   In **Service Benefits**, you can see that the calibration tool you applied for has been activated.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_70a0b84.png)

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_b416c9e.png)

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_fad3dd1.png)

### 2. Bind a Product Line

1. Click **Bind Product Line**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_ab3c626.png)

2. Check the product line and click **OK**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_a16f61d.png)

   > Note: The product line cannot be changed after binding, so please make sure the submitted information is correct.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_924dd73.png)

## Step 4: Log In to Dreamview+

### 1. Log In with an Individual Account

1. Log in to your individual account on [Apollo Studio](https://apollo.baidu.com/workspace/account-center/services).

2. Select the **Vehicle Login** tab and click **Generate**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_a83b979.png)

   > Note: If you have already clicked the Generate button, the page only shows One-Click Copy.

3. Go to the location of the apollo version directory of the software on the IPC, and enter the following commands to enter the docker environment:

   ```bash
   cd apollo version directory location
   aem enter
   ```

4. Click **One-Click Copy**, then paste the plugin information in the docker environment and press Enter.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_89bae24.png)

### 2. Start the Service

1. In the docker environment, enter the following command to start Dreamview+:

   ```bash
   aem bootstrap restart --plus
   ```

   In the browser, open the Dreamview+ page by accessing port 8888 of the machine.

2. Login information at the lower left of the page indicates a successful login.

   ![3.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/3_5341e20.png)

## Step 5: Vehicle-Side Registration and Activation

### 1. Bind the Vehicle and Device

1. In **Settings** > **Account**, select the organization you created and click **close**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_ba39b4c.png)

2. In **Device**, check the cloud logical device to bind to the physical vehicle.
3. Click **Device registration**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_8a0f0ec.png)

### 2. Vehicle Registration

It shows that the calibration tool is under approval. Please contact the internal platform personnel for authentication approval.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_1720132.png)

### 3. Vehicle Activation

After the certificate is approved, it shows the pending-activation state.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_441d08a.png)

Click **Activation** to activate, and it shows the activated state.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_253ee09.png)

After activation is complete, you can use the calibration services (Camera calibration and Lidar calibration) in Dreamview+ on the vehicle.

> Note: After registration and activation are complete, the cloud synchronizes and displays the vehicle's registration and activation status in real time, and shows it in the cloud device list.
