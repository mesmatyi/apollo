## Overview

This is a performance evaluation tool for the chassis drive-by-wire function. It is used to verify whether the vehicle chassis can execute the control commands issued by Apollo accurately and quickly.

### Function Layout
![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_4b866da.png)

## Prerequisites

- The authentication tool has been installed
- The calibration service has been activated and authentication has been completed

## Environment Configuration

### Step 1: Environment Deployment

See the calibration tool [Environment Configuration](./环境配置.md).

### Step 2: Configuration Files
#### Parameter Description

The following is the configuration file `teleop_conf.pb.txt`, located under `/apollo/modules/dreamview_plus_plugins/teleop_tool/conf/`. It is recommended to keep these default settings.

```bash
action_conf {
  #Maximum waiting time for a single command check
  maximum_waiting_time: 3.0
}

gear_conf {
  # Vehicle gear configuration: D gear, R gear, N gear, P gear
  gear: GEAR_DRIVE
  gear: GEAR_REVERSE
  gear: GEAR_NEUTRAL
  # The P gear is optional
  gear: GEAR_PARKING
  record_curve: false
  maximum_waiting_time: 3.0
}

steer_wheel_conf {
  #Default step size for automatic detection
  step: 5.0
  #Whether to record the chassis response curve and the command curve
  record_curve: true
  #Chassis delay time threshold
  delay_time_threshold: 0.2
  #Maximum waiting time for a single command check
  maximum_waiting_time: 3.0
  #Maximum angle difference at the peak
  peak_maximum_angle_difference: 2 
  #Maximum angle difference in steady state
  maximum_angle_difference: 2
  #Steady-state amplitude value
  steady_state_amplitude: 0.5
  #Number of steady-state frames
  steady_state_frame_number: 20
}

brake_conf {
  #Default step size for automatic detection
  step: 5.0
  #Whether to record the chassis response curve and the command curve
  record_curve: true
  #Chassis delay time threshold
  delay_time_threshold: 0.2
  #Maximum waiting time for a single command check
  maximum_waiting_time: 3.0
  #Steady-state amplitude value
  steady_state_amplitude: 0.5
  #Number of steady-state frames
  steady_state_frame_number: 20
  #Maximum percentage difference in steady state
  maximum_percentage_difference: 2
}

parking_brake_conf {
  #Whether to record the chassis response curve and the command curve
  record_curve: false
  #Maximum waiting time for a single command check
  maximum_waiting_time: 3 
}

throttle_conf {
  #Default step size for automatic detection, generally no more than 10%
  step: 5.0
  #Whether to record the chassis response curve and the command curve
  record_curve: true
  #Chassis delay time threshold
  delay_time_threshold: 0.3
  #Maximum waiting time for a single command check
  maximum_waiting_time: 3.0
  #Steady-state amplitude value
  steady_state_amplitude: 0.5
  #Number of steady-state frames
  steady_state_frame_number: 20
  #Maximum percentage difference in steady state
  maximum_percentage_difference: 2
  #Maximum percentage reachable in throttle detection
  maximum_test_percentage: 10
}

speed_conf {
  record_curve: true
  #Steepness value: the maximum acceptable range of sudden changes in speed detection
  jagged_threshold: 0.3
  delay_time_threshold: 0.02
}
#CAN bus refresh frame rate
canbus_clock: 10.0

```

#### Modify Parameters

Change the canbus configuration parameters so that canbus can enter debugging. The file path is `/apollo/modules/canbus/conf/canbus.conf`.


## Procedure


### Automatic Handshake Check


Checks the correctness and delay time of the results after the commands for entering and exiting autonomous driving and for takeover are issued. It needs to be checked manually.

#### 1. Preparation


Select the **Canbus Debug** mode. After starting the **Canbus** module, you automatically enter the automatic handshake check interface.

1. Turn off the autonomous driving switch on the vehicle and click **Start Check**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_648e95f.png)

2. Turn on the autonomous driving switch on the vehicle, then proceed to the next step.


#### 2. Enter Autonomous Driving

1. Click the **Check** button of **Enter Autonomous Driving**.

2. As prompted, confirm whether the autonomous driving switch on the vehicle is on. If it is on, click **Turned On**; if not, you must turn it on first before you can turn on autonomous driving in TeleopTool.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_4a8304a.png)
   
   The result shows the check is **Correct**.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_6c88745.png)

#### 3. Exit Autonomous Driving

1. Click the **Check** button of **Exit Autonomous Driving**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_dd3781a.png)
   
   The result shows the check is **Correct**.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_26b4764.png)
   

#### 4. Enter Autonomous Driving

1. Click the **Check** button of **Enter Autonomous Driving**.
2. As prompted, first turn on the autonomous driving switch on the vehicle, which is required before you can turn on autonomous driving in TeleopTool; confirm and click **Turned On**.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_bf93664.png)
   
   The result shows the check is **Correct**.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_f6f89dc.png)
   

#### 5. Takeover Test
 
1. Click the **Check** button of **Takeover Test**.
2. Operate the remote controller manually to switch the driving mode to manual.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_cae5aa4.png)
   
   The result shows the check is **Correct**.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_e20f3b8.png)
    
    
#### 6. Enter Autonomous Driving

1. Click the **Check** button of **Enter Autonomous Driving**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_dc899f0.png)
 
   The result shows the check is **Correct**.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_cfe5fa7.png)
   
2. After the check is complete and all results show **Correct**, click **Next** to enter the gear test, or select any item to test.
   
   >Note: If a check result shows **Error**, you can click **Details** to investigate the cause and then check again.
   
  

### Gear Check

Gear check: checks the correctness and delay time of the results after the D, R, N and P gear commands are issued. Automatic checking is supported. Default: automatic check.

#### 1. Preparation

1. After entering the gear test, lift the vehicle's drive wheels off the ground and click the **I Have Finished** button.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_e40c5a4.png)

2. Turn on the vehicle's autonomous driving switch and click the **I Have Finished** button.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_f5cc20c.png)

3. Turn on the autonomous driving module switch and click the **I Have Finished** button.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_7c4b9c8.png)

4. Click **Start Check**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_b2e13d9.png)
   
   >Note: Before running the automatic check, first release the handbrake button on the vehicle.


#### 2. Automatic Check

1. Click **Start** to run the automatic check.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_b49b32f.png)
   
   When the gear information of the issued command is the same as that shown in the returned result, the check result is shown as correct; otherwise, the check result is shown as incorrect.
   
   >Notes:
   >- The gear check is purely automatic. The gears to be checked must be configured in the configuration file, by default the D, R, N and P gears. If there is no P gear, you can remove the P gear configuration from the `gear_conf` configuration in `teleop_conf.pb.txt`.
   >- After the automatic check is complete, if an abnormality appears when checking gears manually, just check manually again and it will show normal.
   
2. After the check is complete and all results show **Correct**, click **Next** to enter the steering wheel test, or select any item to test.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_53b4f85.png)
   

### Steering Wheel Check

During left and right steering, checks the consistency between the issued commands and the returned results, and the delay time. Manual check, step check and continuous check are supported. Default: manual check.

#### 1. Preparation

1. After entering the steering wheel check, lift the vehicle's drive wheels off the ground and click **I Have Finished**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_1d9b8bb.png)
   
2. Turn the steering wheel fully to the left and fully to the right respectively, then click **View Details** to view the steering_angle value in the steering wheel details.
 
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_a22c5cd.png)
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_de33e2a.png)
   
3. Enter the steering_angle values from the steering wheel details into the left-turn maximum ground truth and right-turn maximum ground truth input boxes in turn, and click **I Have Finished**. 
4. Adjust the left and right maximum ground truth values as prompted and click **Confirm**.

   The left and right maximum ground truth values are adjusted automatically, and you proceed to the next step.
   
5. Set the rotation speed and click **I Have Finished**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_2b0534f.png)
   
    >Notes:
    >- If you cannot know the rotation speed of the chassis, this item can be left blank. Unit: degrees/second.
    >- After **I Have Finished** for this item, the canbus module is automatically killed and restarted. Please check whether canbus restarted successfully.
   
6. Turn on the vehicle's autonomous driving switch and click **I Have Finished**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_1a0d2c7.png)
   
7. Click **I Have Finished** to enter autonomous driving mode.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_6c23ca5.png)
   
   >Note: If the vehicle automatically engages the handbrake when switching to autonomous driving mode, you need to release the handbrake button manually. Please release the handbrake button according to the actual condition of the vehicle.

8. After all the above steps are complete, click **Start Check**.


  
#### 2. Add Commands and Check

You can do this by manually adding commands to check, by step check, or by continuous check.

##### Manually Add Commands to Check

1. Set the rotation value and click **Add Left Turn** to perform the left-turn check.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_a9e8b09.png)
     
2. Set the rotation value and click **Add Right Turn** to perform the right-turn check.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_09ae13d.png)
     
   >Note: After the first command is added successfully, when the second command is executed again, the value changes accumulate based on the previously executed command, and so on.
     
3. Set rotate-to and click **Add**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_6c21210.png)

   >Notes:
   >- The rotation value is the step size of the left/right steering wheel angle; it is a relative value that is accumulated step by step through addition and subtraction.
   >- Rotate-to refers to an absolute value.
   >- The rotate-to value cannot switch directly from full lock in one direction to full lock in the other direction.
   
4. Click **Curve** to view the response time curve.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_3c3c80d.png)
   
   If the curves of the issued command and the returned result coincide and the delay does not exceed 300 ms (configurable in the configuration file), it is qualified.
   
   >Note: In the curve chart, you can click **Issued Command** to hide the issued command curve and show only the returned result curve.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_76b5d0c.png)
   
   Or hide the returned result curve and show only the issued command curve.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_62c8daf.png)
   
   
   
##### Step Check 

1. Click **Step Check** to enter the step check interface.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_2037a86.png)
     
2. Click **Reset**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_b3fd202.png)

    >Note: The system gives a default step size of 5%. If you want to check other values, you can click the Reset button to set them.
     
 3. In the step size setting interface that pops up, set the **Step Size** and click **Confirm**.

    ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_f422982.png)
     
     >Note: The step size must be greater than the maximum angle difference in steady state in `teleop_conf.pb.txt`.
     
4. Click **Start** to begin the check.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_e8d6d15.png)
    
5. Click **Curve** to view the response time curve.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_e7c0874.png)

   If the curves of the issued command and the returned result coincide, the check is qualified; if they do not coincide, you need to check again.


##### Continuous Check

1. Click **Continuous Check**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_c67c5ab.png)
     
2. Set the amplitude and period, and click **Add** to start the check.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_e8815c2.png)
     
   >Notes:
   >- Continuous check: the control commands are sent at a fixed frequency at the canbus refresh frame rate, to check how the chassis follows and responds.
   >- Amplitude: the maximum left/right percentage the steering wheel needs to be turned to in the continuous check.
   >- Period: the time for all commands to be issued for one round. The period here is best greater than 16 s.
     
   After the check is complete, view the curve chart. If the peak values of the two curves differ little, and the delay is small when the two curves are at the same amplitude, the check is qualified.

   After the check is complete, click **Next** to enter the brake test, or select any item to test.

### Speed Check

Checks the real-time speed change curve when switching between different gears in manual driving mode. Manual checking is supported. Default: manual check.

#### 1. Preparation

1. Turn off the autonomous driving switch on the vehicle and drive the vehicle onto a spacious road. If the handbrake is automatically engaged when switching modes, release it first, then click **I Have Finished**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_ce3ea7c.png)

2. Shift into the D gear and confirm the vehicle's driving direction is **Forward**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_2e3a9a4.png)

3. Shift into the R gear and confirm the vehicle's driving direction is **Backward**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_33ab30c.png)

4. Shift into the N gear and confirm the vehicle's driving direction is **Parked**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_2b629cd.png)
   
5. Click **Start Check**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_a92ea1c.png)
  

#### 2. Set the Check Target

1. Select the different gears in turn.
2. Set the maximum speed and click **Confirm**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_2ffd61a.png)
   
   Drive the vehicle and see whether it can reach the set maximum speed.
  
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_0a15f2f.png)

   >Note: As long as the curve reaches the set maximum speed value, the check passes.
