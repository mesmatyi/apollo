## Overview

Dynamics calibration collects the chassis throttle pedal position, brake pedal position, vehicle speed and acceleration as inputs to the longitudinal dynamics model of the vehicle, and uses machine learning to generate the pedal calibration table for the corresponding vehicle. The generated calibration table has a large data volume and high precision, which improves vehicle control precision.

## Prerequisites

- The authentication tool has been installed.
- The calibration service has been activated and authentication succeeded.


## Module Startup Dependencies

The calibration tool depends on the Localization, GPS and Canbus modules. Before calibration, please make sure the related modules start normally. Because dynamics calibration depends on tensorflow, run the following command to install the tensorflow environment.
```bash
pip3 show tensorflow >/dev/null || pip3 install tensorflow==2.11.0 -i https://pypi.tuna.tsinghua.edu.cn/simple
```
## Procedure

### Step 1: Confirm Parameters

1. In **Mode**, select **Dynamics Calibration**.
2. Click **Setup All** to enable the **Canbus**, **GPS** and **Localization** modules.

4. Confirm the configuration file parameters and click **Next**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_bb6b520.png)

    >Notes:
    >- Configuration file check: confirm the vehicle's speedmax and brakemax in the calibration configuration file; in the vehicle parameters, make sure the brake_deadzone value is smaller than brakemin, and likewise for throttle.
    >- The parameter configuration file path is `/apollo/modules/dreamview_plus_plugins/vehicle_calibration/conf/vehicle_calibration_conf.pb.txt`. You can modify the parameters in the configuration file as needed.
    
    ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_4a0881a.png)
    
    Speed:
    - speed_min: minimum speed
    - speed_max: maximum speed
    
    Throttle:
    - throttle_min: minimum throttle
    - throttle_max: maximum throttle
    
    Brake:
    - brake_min: minimum brake
    - brake_max: maximum brake
    
    Collection percentage:
    - min_collection_percentage_to_calib: the minimum progress at which computing the result is allowed.

### Step 2: Environment Check

When the Canbus status, GPS status and Localization status of the current collection vehicle environment all show green indicators, click **Next**.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_2119922.png)

### Step 3: Data Collection

1. Click **Start Collection**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_0ea9354.png)

   >Note: Choose a flat, wide road, and drive manually or by remote control, keeping the vehicle driving in a straight line as much as possible. Any turns will extend the collection time.
  
   While driving, perform speed, throttle and brake operations according to the calibration conditions (heavy throttle with heavy brake, heavy throttle with light brake, light throttle with light brake, light throttle with heavy brake, and so on). This is expected to take 20 to 40 minutes.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_f94c00d.png)
   
   >Note: The light-colored parts are the initial icons for collection. After the same data is collected, the color deepens; the more values collected, the darker the color. When the required number of frames has been collected, the progress bar shows 100%.
   
2. After data collection is complete, click **End Collection**.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_62b09c5.png)
   
   
   >Note: When the collection progress reaches 80% (this value can be modified through the configuration file), collection is completed automatically.

   

### Step 4: Generate the Calibration Table

Wait for the calibration table to be generated.

![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_eca3a8f.png)

### Step 5: Write the Calibration Table to the Configuration File


1. Click **Replace Parameters** and click **Confirm** to update the calibration table file into the configuration file.

   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_59b54d7.png)

   >Notes:
   >- The format must be kept correct; otherwise the Control module will fail to start.
   >- After obtaining the 3D plot of the brake calibration table, check whether the calibration table is reasonable.
   >- For the throttle calibration table, the table should be as close to a plane as possible.
   >- If the autonomous driving speed limit is far below the maximum vehicle speed, the vehicle approximately has the characteristic that the same throttle opening corresponds to the same acceleration across the whole autonomous driving speed range. If the autonomous driving speed limit is close to the vehicle's speed limit, the acceleration may be smaller when approaching the speed limit.
   >- For the brake calibration table, make sure that at any speed, a larger brake force corresponds to a larger absolute deceleration. If a larger brake force corresponds to a smaller absolute deceleration, the brakes may have physical problems such as thermal fade.

   It shows that the parameters were replaced successfully.
   
   ![image.png](https://bce.bdstatic.com/doc/Apollo-Homepage-Document/Apollo_Studio/image_3ca3f85.png)
