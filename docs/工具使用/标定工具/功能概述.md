The perception module of the Apollo autonomous driving system outputs information about the environment around the autonomous vehicle, where the environment information is relative to the vehicle. The output of each sensor is relative to its own coordinate system. For the vehicle to use sensor information, it needs the transformation between the sensor coordinate system and the vehicle coordinate system. With the transformation between the sensor and vehicle coordinate systems, the environment information output by the sensor can be converted into information about the environment around the vehicle.

The calibration tools include the sensor extrinsic calibration tools and the vehicle calibration tools, which are essential tools for vehicle integration and operations and maintenance.

## Sensor Extrinsic Calibration

Sensor extrinsic calibration obtains the pose of a sensor in the vehicle body coordinate system, and supports LiDAR extrinsic calibration and camera extrinsic calibration.

- LiDAR is one of the main sensors of an autonomous driving platform and plays an important role in perception and localization. Because LiDAR installation positions differ, the transformation between the LiDAR coordinate system and the vehicle coordinate system must be determined before use. In Apollo, the method of obtaining this transformation is called calibration. In Apollo, calibrating the LiDAR extrinsics actually calibrates the transformation between the LiDAR coordinate system and the IMU coordinate system.

- For cameras, in Apollo, calibrating the camera extrinsics actually calibrates the transformation between the camera and the LiDAR.

## Vehicle Calibration Tools

The vehicle calibration tools include vehicle dynamics calibration and chassis calibration tools. Vehicle dynamics calibration is a longitudinal calibration tool that produces the dynamics calibration table required by control, improving vehicle control precision. The chassis calibration tool is a performance evaluation tool for the chassis drive-by-wire function, used to verify whether the vehicle chassis can execute the control commands issued by Apollo accurately and quickly.
