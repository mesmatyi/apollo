### Problem Description:

After upgrading to Apollo 10.0, errors occur because the cache was not cleaned:

* Various header file includes fail, and compilation reports errors:
![](images/cache_not_clean_include_error.png)

* Compilation reports an undeclared inclusion(s) error:
![](images/cache_not_clean_undeclared_inclusion.png)

### Cause:

The caches of 9.0 and 10.0 are not interchangeable. Using them causes problems such as header files not being found or conflicting, which makes compilation fail.

### Solution:
Delete the compilation cache of the workspace, then recompile:

```bash
rm -rm .cache
```
