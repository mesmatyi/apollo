### Directory Description Inside the Container

#### /opt/apollo

Stores installed precompiled packages (including various .so libraries, header files, and configuration and data files distributed with the packages).

- Packages installed with apt install apollo-neo-xx are all stored in /opt/apollo
- The outputs and dependencies of buildtool build xx are also stored in /opt/apollo
- When using buildtool install xx, the package and its dependencies are stored in /opt/apollo

#### /apollo

Stores configuration files. When packages are installed, symlinks to their configuration files are created here.

- When switching configurations with aem profile use, symlinks are created under /apollo
- With buildtool install xx, symlinks to configuration files are created under /apollo
- With buildtool build xx, symlinks to configuration files are created under /apollo

#### /apollo_workspace

The code workspace, which stores the source code of your own project.

- With buildtool install xx, the source code of xx is installed under /apollo_workspace

##### /apollo_workspace/bazel-apollo_workspace

##### /apollo_workspace/bazel-bin

##### /apollo_workspace/bazel-out

##### /apollo_workspace/bazel-testlogs

These directories are symlink directories generated during the bazel build, which make it easy for users to access build outputs. For reference, see: [Bazel output directory layout](https://bazel.build/remote/output-directories?hl=zh-cn)
