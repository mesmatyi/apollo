### Problem Description:

In the source-code environment, compilation fails with: gcc error: unrecognized command line option '-mavx2'

![](images/gcc_mavx2_error.png)

### Cause:

This error indicates that the GCC compiler does not recognize the command-line option -mavx2.

### Solution:

Edit line 746 of scripts/apollo_base.sh and change -mavx2 to -march=native.
This line contains two occurrences; change both to the form described above.
Change it to the following:
job_args="--copt=-march=native --host_copt=-march=native --jobs=${count} --local_ram_resources=HOST_RAM*0.7"

export TF_NEED_CUDA=1

export GPU_PLATFORM="NVIDIA"

![](images/gcc_no_mavx2.png)
