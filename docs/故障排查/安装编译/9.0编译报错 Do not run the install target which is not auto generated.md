### Problem Description:

Compilation fails with: Don't run the install target which is not auto generated

![](images/not_auto_generated.png)

### Cause:

Older versions of the image come with some pre-installed third-party packages. The versions of these third-party packages are incompatible with the current Apollo, and the latest buildtool does not update such packages by default, so the old third-party packages do not match the current Apollo and cause the error.
The latest version of the image has removed these old third-party packages, so you can redeploy using the latest image.

### Solution:
Option 1. Check whether the tag in the .env file of the project is 9.0-latest. If not, change it to that tag, then run aem remove to delete the container and redeploy the project.
Option 2. Add the --keep-3rd-latest parameter when running buildtool build to update the third-party packages and keep them compatible with the current Apollo.
