### Problem Description:

After configuring the ROS environment with buildtool rosenv, compilation fails with an error:

![](images/compile_failed_after_rosenv.png)

### Cause:

To use the ros_bridge feature, you must first manually source ROS's setup.sh file. Otherwise, the linker cannot find ROS's dynamic libraries and fails to link.

### Solution:
Source the setup.sh file that matches the configured ROS version, then compile again:

```bash
source /opt/ros/iron/setup.sh     # If using 22.04 with the iron ROS distribution configured by default
source /opt/ros/galactic/setup.sh # If using 20.04 with the galactic ROS distribution configured by default
```
