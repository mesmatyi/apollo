### Problem Description:

Starting the container fails with: failed to mount local volume...

![](images/start_container_mount_failed2.png)

### Cause:

The user deleted the mount folder on the host machine without running aem remove to clear the old container, which caused the newly started container to fail.

### Solution:

Run aem remove to delete the old container, then start a new container.
