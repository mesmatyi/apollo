### Problem Description:
After starting the container following the standard procedure, the project directory was moved. When re-entering the container, the following problems appear:
* The setup.sh file cannot be found
* Tools such as buildtool and aem cannot be found
* Modules fail to start normally, etc.
![](images/start_container_mount_failed1.png)

### Cause:
When the container starts, it creates a .aem folder in the project directory and mounts it to the installation and output paths of the Apollo packages inside the container, in order to save what this project installs and compiles. After the project directory is moved, the container can no longer find this mount point, so files are lost.
It is recommended not to move the project directory after starting the container.

### Solution:
In the project directory, run aem remove to delete the container and the installed content, then run aem start to restart the container, and redeploy the project afterwards.
