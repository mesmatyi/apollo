### Problem Description:

Compiling a module fails with: gcc: internal compiler error: killed (program cc1plus)

![](images/build_no_resources.png)

### Cause:

The error indicates that the GCC compiler encountered an internal error while compiling C++ code and was killed by some operating system mechanism (such as the OOM killer). This is usually caused by insufficient system resources.

### Solution:

Add the -j and -m parameters to buildtool build to limit the compilation resources.

![](images/build_command_show.png)
