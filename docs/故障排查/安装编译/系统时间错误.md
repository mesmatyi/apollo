### Problem Description:

After every boot, the time reverts to 2023.3.28, and the system time has to be set again.

### Cause:

This is caused by GPS time synchronization. GPS time synchronization was configured previously, and the internal GPS time source is used by default during routine debugging.

### Solution:

Try to correct the clock in one of two ways:
1. Open the Ubuntu system settings: Settings -> Details -> Date & Time, and turn on Automatic Date & Time
2. Note the current time and run directly on the command line: sudo date -s "2023-08-07 12:00:00"

After using it on the vehicle, run ~/apollo-park-generic/start.sh to switch back to GPS time synchronization.
