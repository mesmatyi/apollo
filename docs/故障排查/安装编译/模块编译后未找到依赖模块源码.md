### Problem Description:

After compiling a module, the source code of the modules that cyberfile.xml lists as dependencies cannot be found under /apollo_workspace/modules.

### Cause:

There are two ways to specify dependencies in the cyberfile: binary and src. binary introduces the dependency in binary form, and src introduces the dependency as source code.

### Solution:

Change the dependency type in cberfile.xml from binary to src.
